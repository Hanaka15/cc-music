# cc-music

ComputerCraft music client for **CC:HQ Speakers**.

Uses the public iPod DFPWM API (`https://ipod-2to6magyna-uc.a.run.app/`) with `speaker.playAudio`. Playback controls use HQ Speakers APIs (`speakerStop`, volume, pause/resume).

## Install in-game

```
wget https://raw.githubusercontent.com/Hanaka15/cc-music/main/music.lua music
music
```

Or paste the contents of `music.lua` into a computer.
